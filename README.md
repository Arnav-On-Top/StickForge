An HTML CSS and JS project where u can upload any picture, add a glow, make changes like making it bigger/smaller/rotating/duplicate and add on a A4 size sheet/letter size sheet to make a sticker sheet. User can add multiple images in a single sheet. Exported as a png file.

Demo Link: https://arnav-on-top.github.io/StickForge/

Steps:

1. Click "Start Creating"
2. Choose Your Image
3. Add Glow and select glow color on the left panel
4. Click "Add To Design"
5. Make changes like making it bigger, smaller, rotating or adding a text
6. Once done, click print and it should show a sheet preview. Select A4/Letter and change the margin/sticker gap if u want.
7. Click "Download Sheet" to download a png image

Built as a project for Hack Club's Sticky YSWS [You Ship We Ship] Program.
